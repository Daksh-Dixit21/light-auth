# Security Policy

## Supported Versions

Currently, we only support the latest version of `@daksh-dev/light-auth`. Please ensure you are running the most recent release to receive the latest security patches.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.x  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it privately. Do **not** create a public GitHub issue.

You can report vulnerabilities by:
- Sending an email to [dixitdaksh21@gmail.com](mailto:dixitdaksh21@gmail.com)
- Contacting me on GitHub: [@Daksh-Dixit21](https://github.com/Daksh-Dixit21)
- Creating a private security advisory on GitHub (if available)

Please include as much detail as possible, including:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We take security seriously and will respond as soon as possible to investigate and address the issue.

Thank you for helping keep this project secure!
